# ⚙️ Menu Classic For Win 11 - x64

A lightweight utility to restore the **classic Windows 10 Context Menu** (Right-Click Menu) experience on Windows 11.

---

## ✨ Features

* **Classic Context Menu:** Restores the full, traditional Windows 10 right-click menu on Windows 11.
* **Flexible Toggle:** Includes the option to easily switch back to the default Windows 11 context menu when needed.
* **x64 Architecture:** Built specifically for 64-bit systems.

## 📥 Installation

1.  Go to the [Releases] page and download the latest version of **Menu Classic For Win 11 - x64**.
2.  Run exe file.

## 🚀 How to Use

Just **download and run** the executable. The tool will automatically detect your current right-click menu style.

* If you are currently using the **Windows 11 (Modern) context menu**, a **"Classic Menu"** button will appear, allowing you to switch back to the Windows 10 style.
* If you are using the **Windows 10 (Classic) context menu**, a **"Modern Menu"** button will appear to revert to the Windows 11 style.
